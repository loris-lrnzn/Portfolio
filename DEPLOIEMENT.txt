  1. HTTPS AVEC LET'S ENCRYPT
  ────────────────────────────
  (À faire dès que le DNS lorislorenzini.fr est propagé vers 149.202.61.240)
  Vérifier la propagation : https://dnschecker.org/#A/lorislorenzini.fr

  Sur le VPS :
    sudo apt install -y certbot python3-certbot-nginx
    sudo certbot --nginx -d lorislorenzini.fr -d www.lorislorenzini.fr

  Mettre à jour ~/Portfolio/.env.prod :
    FRONTEND_URL=https://lorislorenzini.fr
    DJANGO_ALLOWED_HOSTS=lorislorenzini.fr,www.lorislorenzini.fr
    CORS_ALLOWED_ORIGINS=https://lorislorenzini.fr,https://www.lorislorenzini.fr
    CHATBOT_MEMORY_COOKIE_SECURE=True

  Mettre à jour nginx/default.conf (en local) :
    Remplacer : server_name _;
    Par       : server_name lorislorenzini.fr www.lorislorenzini.fr;

  Puis redéployer :
    ./deploy.sh
